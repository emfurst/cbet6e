What’s here

  1. A scientific computing stack — for computing. Python and Jupyter notebooks, the thermo package, and reference data for solving equations of state, fitting data, and plotting — a core engineering skill you use with or without AI. Run the notebooks on their own, or alongside an AI coding assistant in your editor (Claude Code, Copilot, Cursor) that can execute the cells. Each chapter’s notebooks are listed on its page.
  2. AI study aids — for studying. Each chapter has a notation primer you paste into a chat assistant (Claude, ChatGPT, Gemini, and others) so it answers in this book’s symbols, sign conventions, and equations, plus shared study prompts for explanations, quizzes, connecting ideas across chapters, and walking through an answer key.

Rule of thumb: studying → grounded chat; computing → the scientific computing stack. Always check AI output against a worked example, a limiting case, a units check, or a known data point.

Using the notation primer

  1. Open the chapter you are working on, from the list below.
  2. Click Copy notation primer for AI and paste it into your chat as the first message.
  3. Then ask your thermodynamics questions — or copy one of the study prompts and fill in the bracketed parts.
  4. Starting a new chat? Paste the primer again first.

Long-paste warning. Some chat input boxes silently cut off very long pastes. The primer ends with a line reading END OF NOTATION PRIMER and asks the assistant to confirm it received that line — if it didn’t, paste the primer in two halves or attach it as a file.

What’s on each chapter page

Every chapter page has the same two parts:

  • AI grounding — notation, symbols, and governing equations. A copy-ready notation primer (and a downloadable chNN-notation.md for coding assistants) that pins the chapter’s conventions, symbols, and governing equations in the book’s form. It is cumulative — it already includes earlier chapters’ notation, so you only need the page for the chapter you are in.
  • Codes. The Python scripts and Jupyter notebooks relevant to that chapter, with direct download links.

The study prompts are the same for every chapter, so they have their own page rather than repeating on each — use them after pasting the chapter’s notation primer.
