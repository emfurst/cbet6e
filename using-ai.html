How to use AI with this book

AI tools change month to month, but the useful habits change more slowly. This is a short orientation. The fuller, living guide is coding-with-ai. We recommend no single vendor — any capable current tool works.

Two worlds

There are two ways to bring AI to your work. They are good at different things:

  • Web chat (Claude, ChatGPT, Gemini, …) — best for explanation, interpretation, planning, and studying. It has no view of your files; you paste context in.
  • Tools that live with your code (Claude Code, Copilot, Cursor) — best for actually writing and running code, because they can read your files, edit them, and execute cells.

Ground it in this book

Before asking a chat about a chapter, paste that chapter’s notation primer first, so the assistant answers in this book’s symbols, sign conventions, and equations instead of drifting. In a code project, keep the chapter’s chNN-notation.md file alongside your notebook so an editor assistant reads the same conventions automatically. Each chapter page has both, and the shared study prompts give tested starting points.

What it’s good at — and what to paste

Errors, stack traces, and log output are exactly what chat models parse well; paste the whole message with a sentence of context. For learning, ask for explanations, quizzes, or connections between ideas. Bring the relevant context with you — the model only knows what you show it.

Always verify (and cite)

Treat AI output as a capable but unreliable colleague’s: check it against a worked example, a limiting case, a units check, or a known data point before trusting it. When AI use is substantive, disclose it as your course or venue requires; the coding-with-ai guide covers verification and citation in more detail.
