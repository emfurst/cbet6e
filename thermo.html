The thermo package

The models of this book in Python: 24 modules, one import.

thermo is a library of reusable methods: the cubic equations of state, the activity coefficient models, UNIFAC, the phase-equilibrium solvers, chemical reaction and ionization equilibrium, and the routines that draw the property charts. Each is validated against known limits and against the illustrations worked in the book.

Seven of Chapter 6’s examples appear in two forms: a self-contained notebook that builds the method procedurally from the governing equations, and a second that imports thermo. The package version of each is shorter by 23 to 60 percent, and the lines it drops are the ones that rebuild the equation of state. Chapter 6 develops the Peng–Robinson equation, which is why the pairs are there and not elsewhere; later chapters import the package and leave the derivation to the text.

Python and Aspen Plus® are complementary parts of a practicing engineer’s toolbox, not a learning tool and a real one. Scientific computing in Python supports data analysis, custom calculations, and prototyping, and runs with nothing but a Python install. A process simulator is the specialized tool for flowsheets, unit operations, and plant-scale design, and it offers many thermodynamic property methods, so a calculation that would take a long time to assemble by hand is available directly. The same flash calculation returns different answers under Peng–Robinson, NRTL, UNIQUAC, or UNIFAC. The engineer selects among them: which model suits the mixture and the range of conditions, what data its parameters were fitted to, and how far it can be trusted outside that range. Chapters 6, 7, and 9 derive those models; Chapters 10 and 11 apply them to phase equilibrium.

Getting it

The package travels with the notebooks, so anyone who can run a chapter notebook already has it. Its dependencies are NumPy, SciPy and pandas, and nothing else. To set up either Colab or a local install, see Getting started.

import sys; sys.path.insert(0, "..")   # from a chapter folder
from thermo import PengRobinson, UNIFAC

insert(0, ...) rather than append: another package on PyPI is also called thermo, and an installed one would otherwise be found first. See Where these skills go next.

Units are SI throughout: temperature in K, pressure in Pa, molar volume in m³/mol, energies in J/mol. Critical pressures in pure_property.csv are stored in bar and converted to Pa when the table is loaded.

The data behind it

Parameters and constants are plain CSV in code/data/ rather than compiled into the code, so a value can be inspected, checked against the NIST WebBook, or added to. thermo.data loads all of them: the 618-compound pure-fluid property table, the reaction property table, the UNIFAC group tables, and the binary interaction parameters.

The pure-component constants are adapted, with corrections, from Reid, Prausnitz and Poling, The Properties of Gases and Liquids, 4th ed. (McGraw-Hill, 1986), Appendix A. The same table has been distributed with this book’s software since the fourth edition. One caution: the ideal-gas heat capacities in that file are the Reid–Prausnitz–Poling set, not the set printed in Appendix A.II. The two sets differ, so a notebook that reproduces a printed table states which of them it loads.

Reading the source

The package is at code/thermo/ in the code repository, under the MIT license. Every module opens with a docstring naming the sections of the book it implements, and equation numbers appear in comments beside the lines that evaluate them, so a printed equation can be traced to the code that computes it.

Found an error, or need a model that is not here? The issue tracker is open. The package is maintained through the life of the edition, so a correction reaches readers without waiting for a reprint.

Where these skills go next

This package is deliberately small. It implements the models this book derives, in the book’s own notation, with the iteration visible so that you can read what a flash calculation actually does. That is a teaching goal, and it has a natural end: once you can write a bubble-point calculation, the next question is what practicing engineers and researchers use to do it at scale. Three open-source projects cover most of what they use, and everything you have learned here transfers to them.

projectwhat it is for
CoolPropHigh-accuracy pure-fluid properties from multiparameter Helmholtz equations of state — the reference-quality formulations, for about 120 fluids. Where this book uses a cubic and accepts a few percent, CoolProp gives you the measured surface. It is the tool for cycle calculations and for checking a cubic’s error. A C++ core with a Python interface.
ChEDL thermoChemical-engineering property estimation and phase equilibrium across a large compound database, with automated flash routines and group-contribution methods that estimate what you have no data for. The closest relative of this package, at production scale. See the naming caution below.
CanteraChemical kinetics, reacting flows, and combustion — multiphase equilibrium by Gibbs energy minimization, and the reaction mechanisms Chapters 13 and 14 stop short of. Widely used in combustion and reactor research.

A reasonable exercise once you have finished a chapter: work an illustration here, then reproduce it with one of these. Where the answers differ, the difference is the model, and you now know enough to say which one you trust and over what range.

One caution about the name. ChEDL’s package is also called thermo, and it is the one pip install thermo installs. If both are present, the installed package shadows this one and every notebook here imports the wrong library. Install ChEDL’s in a separate environment, or import it under another name. The line at the top of every notebook, sys.path.insert(0, ".."), puts this book’s package first for exactly this reason — it must be insert, not append.
